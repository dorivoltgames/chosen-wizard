# 마법 공명 개선안 — 미배포 체험판

원래 게임의 재미인 랜덤 탄생, 직접 치르는 시험, 특성에 따른 사건,
한 손가락 회피 전투, 카드 성장, 뜻밖의 엔딩을 기준으로 복원했다.

## 원래 인생 흐름

- 7세 입학시험, 학교 사건, 12세 비행시험, 16세 체력장, 17세 졸업을 모두 거친다.
- 18세에 모험을 떠나거나 고향에 남는다. 고향의 랜덤 사건도 기존 구현을 사용한다.
- 텍스트 위주였던 3경로 선택은 본편에서 제외했다. 원래 39개 엔딩을 사용한다.
- 이전 2.0에서 얻은 8개 엔딩의 저장 키, 이름, 공유 링크, 전생 기록은 남긴다.
  달성한 이전 엔딩은 도감의 이전 이야기 목록에서 볼 수 있다.

## 카드가 전투에 미치는 확장

태어난 속성은 재료 하나를 제공한다. 획득한 기존 카드가 다른 재료를 제공하면
두 재료의 공명이 열린다. 첫 전투의 첫 카드 보상에는 조합을 완성할 수 있는
카드 하나를 포함한다. 카드와 나머지 무작위 보상 중 선택은 플레이어가 한다.

| 조합 | 재료 | 효과 |
|---|---|---|
| 열충격 | 불꽃 + 서리 | 폭발 피해, 짧은 기절 |
| 화염 회오리 | 불꽃 + 바람 | 3초간 지속 피해 |
| 뇌전 분신 | 번개 + 분신 | 추적하는 번개 3연타 |
| 생명의 결계 | 수호 + 생명 | HP 회복, 상한이 있는 보호막 |
| 월식 | 어둠 + 생명 | 피해, HP 회복 |
| 빙하 파쇄 | 서리 + 수호 | 피해, 짧은 공격 감속 |

위험한 공격을 실제로 피할 때만 1칸 충전한다. 3칸을 채우면 자동 발동하고,
피해를 받으면 1칸을 잃는다. 빈 탭이나 튜토리얼 회피는 충전하지 않는다.
기존 자동 마법, 한 칸 이동, 보스 힘겨루기는 그대로다.

조합은 한 번에 하나를 준비한다. 새로운 조합이 완성되는 카드를 고르면
그 조합이 준비된다. 전투 사이에 마법서에서 바꿀 수 있다. 추가 재료 카드는
3단계까지 공명을 강화한다. 변신과 동료, 기존 엔딩 판정도 유지한다.

## 바로 해보기

`npm run preview` 후 `http://127.0.0.1:8765/?playtest=1`로 연다.
"새 마법 조합 · 전투 체험"은 샘플 캐릭터로 실제 일반전, 카드 보상, 보스전을
차례대로 진행한다. 본편은 "태어나기"로 시작한다.

비교 체크박스를 켜면 같은 샘플과 전투 난수 시드에서 공명만 비활성화한다.
전투 체험은 엔딩 완료 처리나 도감 해금을 호출하지 않는다. 체험판의 본편
진행 저장소도 별도 키를 쓴다. localhost, 파일 빌드, playtest URL은 운영 통계를
전송하지 않는다. 현재 라이브 서비스나 Cloudflare Worker에는 배포하지 않았다.

## 검증 범위

`npm test`는 실제 전투 엔진의 회피 입력과 판정, 6종 효과의 실제 HP/보호막
변화, 충전과 피격, 조합 선택과 성장, 이전 저장/링크 호환을 검사한다.
인생 흐름 검사는 시험 점수와 승패를 고정해 두 선택의 경로를 검사한다.
이는 재미나 전체 난이도 균형의 증명이 아니다. 플레이 감각은 체험 후 판단한다.
