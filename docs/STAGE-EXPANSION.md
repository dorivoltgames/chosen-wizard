# 스테이지 확장 — 미배포 체험판

원래 탄생·시험·학교생활·성인식과 한 손가락 회피 조작을 유지했다.
모험은 5구간에서 8구간으로 늘었다. 기존 10지역에 새 지역 3개가 합류한다.

1. 초원 / 요정의 숲
2. 사막 / 안개 늪 / 해적 해안
3. **수정 동굴**
4. 설원 / 불꽃 화산
5. **태엽 시계탑**
6. 던전 / 하늘 유적
7. **별빛 항로**
8. 마왕성

| 지역 | 일반 몬스터 | 보스 | 주요 패턴 | 보스 유물 |
|---|---|---|---|---|
| 수정 동굴 | 수정 진드기, 프리즘 박쥐, 석영 달팽이 | 프리즘 사슴왕 루미 | 두 줄을 막는 굴절 광선. 체력 절반부터 쌍무지개 | 프리즘 심장: 공명 발동 시 추적 파편탄 2발 |
| 태엽 시계탑 | 태엽 병정, 진자 유령, 황동 풍뎅이 | 시간지기 똑딱 | 느림/빠름이 교차하는 진자 스윙. 체력 절반부터 태엽 폭주 | 멈추지 않는 태엽: 회피 4회마다 모든 주문 대기시간 1.5초 단축 |
| 별빛 항로 | 별 해파리, 혜성 여우, 초승달 가오리 | 별을 삼킨 고래 노바 | 빈 줄이 이동하는 별비. 체력 절반부터 역순 궤도 낙하 | 별고래의 등불: 별 3개로 피격 피해 30% 감소 및 반격 |

12종 모두 별도 도트 스프라이트를 사용한다. 큰 보스는 원래 렌더러의 도형·외곽선·피격 표현으로 움직인다.
각 지역은 수정 암반, 거대 시계/회전 톱니, 고리 행성/별똥별 배경을 갖는다.
새 보스의 공격은 기존 이동 간격으로 회피 가능한 배열만 생성한다.
기존 마왕의 3막, 변신, 동료·대화·잠입, 특성 사건과 엔딩 분기는 유지한다.

보스 유물은 무작위 카드 풀에서 나오지 않고 직접 격파해야 얻는다.
새 지역별 음식, 현상수배 몬스터, 쓰러짐 엔딩 3개도 연결했다.
기존 39개 엔딩을 유지하며 활성 엔딩은 42개다. 이전 2.0의 8개 기록은 보존한다.
Cloudflare 소스의 허용 ID에도 새 결과를 추가했지만 서버에 배포하지 않았다.

## 체험

`npm run preview` 후 `http://127.0.0.1:8765/?playtest=1`을 연다.
"새 지역 3곳 · 몬스터와 보스 체험"은 지역에 맞춰 성장시킨 샘플로 몬스터전,
카드 보상, 보스전, 유물 획득을 진행한다. "태어나기"는 8구간이 연결된 본편이다.

독립 실행 HTML은 `node tools/build-playtest.mjs <출력 경로>`로 만든다.
체험판은 별도 저장 키를 쓰며 운영 통계를 전송하지 않는다.

## 검증

- `npm test`: 8구간 전체 수치 배열, 12종 도트, 지역 연결 데이터, 새 보스 24경기,
  시그니처 패턴, 유물의 실제 전투 효과, 기존 인생·저장·공유 호환을 검사한다.
- 시험 점수를 고정하고 실제 전투를 진행한 40개 탄생: 602경기에서 비정상 수치나
  무한 전투 없음. 37개는 8구간을 완주하고 3개는 기존 사건의 다른 결말로 끝남.
  이는 일정한 회피 입력과 카드 선택을 쓰는 자동 진행 결과이며, 인간 플레이어의
  승률이나 재미를 뜻하지 않는다.
- 화면 검증은 별도 브라우저에서 진행한다. 이 개선안은 아직 라이브에 배포하지 않았다.
