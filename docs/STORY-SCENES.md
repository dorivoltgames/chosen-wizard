# 선택 장면과 신규 보스 조정 — 미배포 체험판

기존의 탄생, 시험 세 종류, 학교생활, 성인식, 고향/모험 분기와 한 번 탭하는
회피 조작을 유지한다. 원래 사건의 선택과 실제 결과를 기존 도트 장면에 연결했다.
연출 계획은 난수를 사용하거나 능력치·동료·아이템을 바꾸지 않는다.

## 화면에서 보이는 변화

- 성인식: 모험과 고향 이정표, 주민들, 선택한 방향으로 걷는 캐릭터.
- 인연: 동물이 다가오거나 작별 인사를 하고, 실제 합류한 동료만 이후에도 따라온다.
- 서고·대장간·거래·샘·보물 사건: 책장/빛나는 책, 망치와 불꽃, 상대 인물과 소품.
  확률형 선택의 성공을 미리 보여주지 않는다. 결과를 받은 뒤 변신·합류·회복 등을 표시한다.
- 학교와 고향 생활: 실제 학교와 직업 플래그에 따라 학생, 간판, 빵집, 밭, 가게,
  교실, 경비소가 나타난다. 기사·궁술 학교 이름도 원래 클래스에 맞춘다.
- 지역 갈림길: 실제 후보 지역의 배경색, 아이콘, 보스가 보이는 문.
  신규 지역에 도착하면 해당 지역 문과 몬스터가 나타난다.
- 신규 마법 조합: 선택 가능한 카드 구체, 선택/완성 연출, 이후 남는 속성 구체.
  전투 중 공명 발동 효과와 조작은 기존 체험판과 같다.
- 신규 보스 유물 세 종류: 실제 획득 시 큰 아이콘과 빛, 이후 캐릭터 주변을 도는 유물.
- 신규 보스 2단계: 수정 조각, 회전 톱니, 궤도 별이 나타나 전환을 알린다.

모든 사건에 별도의 긴 컷신을 만든 것은 아니다. 공통 행동과 실제 결과 반응을
연결하고, 위 사건군에 전용 소품과 장면을 제공한다. 전투 화면에는 이 생활 연출을
표시하지 않아 노트와 회피 공간을 가리지 않는다. 이동 연출은 약 0.75초이며,
기기의 동작 줄이기 설정에서는 0.18초다.

## 난이도 비교와 조정

신규 보스는 단일 체력 막대와 중간 패턴 전환을 사용했고, 마왕은 세 막을 사용해
후반 캐릭터가 노바를 지나치게 빨리 잡는 차이가 있었다. 새 보스의 체력 예산과
후반 패턴 템포/휴식 간격을 조정했다. 마왕, 플레이어 이동 간격, 공격 예고와
기존 회피 가능성 검사는 그대로다.

| 보스 | 체력 예산 배율 | 2단계 박자 배율 | 2단계 휴식 배율 |
|---|---:|---:|---:|
| 루미 | 1.15 | 1.08 | 0.90 |
| 똑딱 | 1.40 | 1.15 | 0.82 |
| 노바 | 2.00 | 1.14 | 0.84 |

기존 체험판에서 실제 전투로 진행한 20개 인생 중 비교 지점까지 온 18개를
저장했다. 이전/이후 모두 같은 능력치·카드·난수·완전 회복 상태로 다시 싸웠다.
회피 입력은 위협 노트가 현재 줄에 0.42초 이내로 다가올 때 한 칸 이동하고,
힘겨루기에서는 탭하는 고정 정책이다.

| 비교 | 이전 격파 시간 중앙값 | 조정 후 |
|---|---:|---:|
| 루미 — 각 인생의 해당 구간 캐릭터 | 28.3초 | 31.0초 |
| 똑딱 — 각 인생의 해당 구간 캐릭터 | 23.4초 | 31.7초 |
| 노바 — 같은 후반 캐릭터 18개 | 16.4초 | 27.7초 |
| 마왕 — 같은 후반 캐릭터 18개 | 47.0초 | 47.0초 |

이는 전투 지속시간의 통제 비교다. 사람의 승률이나 재미, 모든 빌드의 난이도
순위를 뜻하지 않는다. 늦은 회피와 일정 간격 연타 정책도 함께 기록했다.
노바는 마지막 전초전으로 늘리고 마왕의 세 막은 최종전으로 남겼다.

`tools/compare-bosses.mjs <보고서.json>`으로 인생을 생성해 비교한다.
`tools/compare-bosses.mjs <보고서.json> <저장한 보고서.json>`은 같은 캐릭터
자료를 재사용한다. 검증 요약은 배포용 파일과 함께 별도로 제공한다.

## 체험과 검증

시작 화면의 **선택 이벤트 · 장면 체험**에서 성인식, 동료, 서고, 갈림길,
새 조합, 세 유물 획득, 변신과 대장장이 사건을 바로 볼 수 있다. 샘플 인생이므로 본편의 사건 확률과
보스 격파 조건을 바꾸지 않는다. **태어나기**는 같은 연출이 연결된 본편이다.

- `npm test`: 44개 통과. 실제 선택 결과와 합류/조합/유물 연출 일치,
  난수 불변, 기존 인생·저장 호환, 신규 전투, 후반 격파 시간 역전 방지를 검사한다.
- 브라우저에서 고향 빵집, 동료 합류, 서고, 지역 이동, 조합 완성, 별고래 유물을 확인했다.
  375px 화면에서도 카드와 선택지가 동작하며 콘솔 오류가 없었다.
- 체험판은 별도 저장 키를 쓰고 운영 통계를 보내지 않는다. 게임과 Cloudflare 모두
  이번 수정본을 배포하지 않았다.
